# sis.-organ.-gorodskih-festivaley
# Городские фестивали

## Назначение
Приложение для организации и управления городскими фестивалями. Позволяет вести учёт фестивалей, площадок, участников и расписания мероприятий, а также проверять доступность площадок для проведения событий.

## Целевая аудитория
- Администраторы городских культурных учреждений
- Организаторы фестивалей и мероприятий
- Участники творческих коллективов
- Городские жители и туристы

## Предметная область
Организация городских культурных мероприятий: планирование фестивалей, распределение площадок, регистрация участников, составление расписания и контроль занятости площадок.

## Основные сущности
- Фестиваль
- Площадка
- Участник
- Мероприятие (событие в рамках фестиваля)

## Основные функции
- Проверка доступности площадки для проведения фестиваля
- Регистрация нового фестиваля с указанием названия, даты и места проведения
- Расчёт стоимости участия в фестивале в зависимости от категории участника

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей и ролей;
- разработка REST API;
- контейнеризация приложения;
- настройка CI/CD.
